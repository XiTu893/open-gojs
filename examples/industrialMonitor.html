This SCADA industrial diagram displays a mock water treatment setup. Some nodes act as monitoring panels, and simulated data is updated periodically. GoJS is a common choice for industries wishing to make SCADA diagrams, P&ID (piping and instrumentation diagram) software, Manufacturing Operations Management diagrams, process flows, and more.

For a control-room style screen built with the same concepts - with live alarms, moving analog indicators, and clickable equipment - see the High-Performance HMI Operator Screen sample.

Although this sample is meant to demonstrate monitoring, users can rotate valves, and move nodes to see the link's built-in AvoidsNodes routing.

The dark and light themes are controlled using the ThemeManager.
