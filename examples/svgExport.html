SVG 渲染与导出（Diagram.makeSvg / makeImageData）

核心新增：diagram.makeSvg(opts)（返回 <svg>）、 diagram.makeImageData()（PNG dataURL）、 go.SvgRenderer.render/renderToString（静态导出）。 交互仍由 CanvasRenderer 承担；SVG 为当前内容的静态快照。

说明

      
    
        
  • makeSvg：导出当前内容为 SVG 元素；选项 scale / bounds / background / includeAdornments / layers。
    • 
        
  • makeImageData：取当前画布 PNG dataURL（配合 <a download> 即可下载）。
    • 
        
  • go.SvgRenderer.renderToString(diagram, opts)：直接拿 SVG 字符串。
    • 
        
  • 图中含线性渐变、圆角矩形、虚线连线、箭头与阴影，均可被 SVG 导出。
    • 
        
  • mermaid 渲染的图同样可用：go.Mermaid.exportSvg / downloadSvg。
