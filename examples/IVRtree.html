Theme: Screen Reader:

An IVR tree, or Interactive Voice Response Tree, is typically used by automated answering systems to direct calls to the correct party. This particular example is for a car dealership to route calls.

This Interactive Voice Response Tree (IVR tree) has nodes that contain a collapsible list of actions, controlled by a PanelExpanderButton, with a TreeExpanderButton underneath the body. See the learn page on buttons for more GoJS button information.

Once CommandHandler.isFocusEnabled has been set to true, the root node becomes the GoJS CommandHandler.focus, as shown by a double-colored dashed box around the node. This allows the user to use the arrow keys to change focus, Space to select the focused Part, and Enter to go into Nodes and click buttons such as the "PanelExpanderButton" or "TreeExpanderButton". Read more about Keyboard Control.

Once CommandHandler.isVirtualPointerEnabled has also been set to true, then when the user holds down the Shift key, it shows a virtual pointer that allows the user to use Shift-Enter and Shift-arrow keys to drag nodes. The user can always toggle "keyboard control mode" using the Ctrl-Alt-Enter keyboard command.

For another sample demonstrating screen-reader assistance, see Accessibility sample.

The dark and light themes are controlled using the ThemeManager.
