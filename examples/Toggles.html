This sample shows many examples of how to use the predefined toggle buttons inside GoJS and how they can be customized. These premade Panels exist for common structures needed in many Node templates. To create a toggle switch call: 

go.GraphObject.build('Toggle', null, 'choice1')

null is in the place of the optional properties object, 'choice1' is the name of the boolean data property whose value is toggled by this button. This represents the value of the toggle switch.

Add a GraphObject to the "Toggle" to provide a label for the switch.

For more information on these predefined panels see Buttons. You can see how they are defined in Buttons.js.
