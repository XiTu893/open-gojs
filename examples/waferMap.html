This sample depicts a wafer map diagram, a tool used in semiconductor manufacturing. It shows both the oxide thickness and usability of each die (chip) on the wafer via a tool tip, and the overview viewing modes can be toggled at the top right of the diagram. Enter the desired die dimensions and wafer size to calculate the die per wafer and see generated mock data.

It uses the PackedLayout extension to fit several die nodes into an optimal circle shape, and a Group to create the wafer border. The status of each die is stored in the node data array, and its color is determined by a corresponding data binding.
